Selected direction · 03 Connected HJ

把一个符号，延伸成整套批发品牌系统。

连接的 H 与 J 代表货品、买手与市场之间的连接；荧光节点代表快速测试与新机会。这一轮关注的不是装饰，而是它能否在商城、包装、报价和社媒中持续保持识别。

CONNECTED HJ / ROUND 02
01 / SYMBOL REFINEMENT

三个同源版本，只调整性格，不推翻概念。

重点比较圆润程度、时尚感和 B2B 专业度。A 是最均衡的版本，也是建议继续精修的母版。

03A · CONNECTED CORE首选

平衡、清楚、可缩放

H 与 J 共用连接线，在 24px 小尺寸仍能辨认。适合网站、社媒、包装和单色印刷。

03B · CHAIN LINK

更像链条，更有时尚感

弧度和比例更活跃，适合年轻零售渠道；但在单色烫印时，顶部节点略抢注意力。

03C · OPEN FRAME

更结构化，更像供应商

开放边框表达系统与输出能力，适合展会和 B2B 文件；用于首饰卡时稍显工业。

02 / RESPONSIVE LOCKUPS

同一套 Logo，按空间自动切换。

主标用于网站与展会；竖版用于包装；纯 HJ 用于 favicon、头像、水印和极小尺寸。不是每个地方都硬塞完整品牌名。

03 / COLOR SYSTEM

Carbon、柔白与 Signal Lime 成为唯一主色。

柔白承担大面积内容，Carbon 建立专业度，Signal Lime 只标记“新款、速度与行动”。钢银负责中性背景和分隔；错误与缺货颜色属于系统状态，不进入品牌色板。
